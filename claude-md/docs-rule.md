## Up-to-date documentation

Before writing or changing code that uses a third-party library, framework, SDK, API or CLI, look up its current documentation with the Context7 MCP tools: resolve the library ID first, then fetch the docs for the version this project uses. Do not rely on memory for function names, parameters, config keys or CLI flags. If Context7 has no entry for the library, say so and use the project's own docs or source instead.
